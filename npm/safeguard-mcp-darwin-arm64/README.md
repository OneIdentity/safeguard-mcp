# @oneidentity/safeguard-mcp-darwin-arm64

macOS Apple Silicon (arm64) native binary for the [One Identity Safeguard MCP server](https://www.npmjs.com/package/@oneidentity/safeguard-mcp).

This package is a platform-specific dependency and is **not meant to be installed
directly**. Install the main package instead — it pulls in the correct binary for your
platform automatically:

```bash
npx -y @oneidentity/safeguard-mcp
```

See <https://github.com/OneIdentity/safeguard-mcp#readme> for documentation.
